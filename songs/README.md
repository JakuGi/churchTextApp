# Ukážkové piesne

Tieto súbory slúžia len na vyskúšanie aplikácie a ukazujú podporované formáty
(vlastný, OpenSong, OpenLyrics, viac piesní v jednom súbore). Texty sú
demonštračné, nie sú to oficiálne znenia zo spevníkov.

Načítaš ich v appke: **Nastavenia → Načítať ukážkové piesne**.
Vlastné piesne pridávaj cez **Knižnica → Načítať priečinok**.
